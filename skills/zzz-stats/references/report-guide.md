# 报表使用与口径

需要解释指标、角色来源或报表交互时读本文件。它是运行期参考，不是模板开发规范。

## 数据范围

官方统计提供 S 级逐金记录，不是完整逐抽记录，也不含四星。报表只解释本次采集覆盖的版本；缺失历史不能当成用户从未抽过。

官方 index 汇总总抽数与 S 数不含邦布，六频道合计不能直接与该汇总比较。

## 成本与不歪率

- 当前垫抽已经含在官方总抽里，但尚未结算成一金，所以每金与每 UP 成本扣除垫抽。
- 一轮 UP 成本包括拿到 UP 前歪出的抽数；大保底不能只看最后那条 UP 记录。
- 默认详情行表示距上一个金的抽数；频道首金表示从频道开头累计到首金的抽数。
- 「真实抽数」把歪成本合并到下一只 UP，表示轮总成本，不改变右栏角色汇总。
- 不歪率是 50/50 胜场占 UP 轮数的比例，保底获得的 UP 不算胜场。
- 折线始终按全局累计计算，版本筛选只改变柱子，不重算折线。
- 详情条长在本频道当前视图内比较成本，不是跨频道统一刻度。

## 代理人汇总

右栏跨全部六频道汇总角色，不跟左栏频段或版本筛选变化；音擎与邦布不计入。

- 影画按角色记录出现次数减一反推；不是读取游戏内影画等级，记录缺失会少算。第一只在来源提示中叫「本体」。
- UP 角色总抽数是它各轮 UP 成本之和，包括期间歪出的；歪次数是追它时歪过的轮数。
- 非 UP 角色只显示影画，提示列出常驻获得、追某 UP 时歪出或十连副金等来源，不把 UP 的成本算到非 UP 身上。
- 每次获得的版本/时间与末行均抽在悬浮提示中查看；来源不完整时不补造记录。

## 称号与标签

按模板配置与本次数据自动生成，不是人群百分位或对未来抽卡的预测。

常见标签：十连多金、连续 UP/连续歪、先歪但总成本更省、累计不歪率从低点回升、历史欧非来回变化。多金按一组实际金数区分双金/三金等；轨迹标签描述过去，不一定代表当前状态。

角色欧非标记相对获取次数对应的期望成本判断，平档不标；非 UP 角色没有自己的获取成本，不判欧非。不要为示例未出现的档位捏造角色。

## 交互与分享

主图和详情各有独立版本过滤；全部取消会回到全显示。详情列表自然向下展开，切频段后页面高度可能变化。

右上角眼睛循环全显示、只隐藏 UID、同时隐藏 UID 与昵称。公开截图先切全打码；但 HTML 内嵌原始数据，眼睛并未删除敏感字段。分享文件与只分享打码截图是两件事。

用户只想用报表时不要修改模板。要求定制配色/口径/版式时，应明确是修改 skill 的开发任务，另外检查开发规范，不在采集期间顺手改算法。

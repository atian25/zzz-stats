# 抽卡报表规则（单屏 HTML）

`data/` 下的官方 JSON 是唯一数据源。以下规则是逐轮打磨后定稿的报表口径与呈现约定，实现报表时照此执行。

## 1. 口径

- **UP 周期**：从上一金之后到该 UP 的抽数。`off` = 期间非 UP 的 S 消耗抽数，`up` = off 之后到 UP 的抽数，`total = off + up` 即该轮总成本。
- **同一发十连里的非 UP 金归同池 UP 轮**：它若在 UP 之后出（如南宫羽十连里的猫又），把「该金 − 上一金」的差值并入这一轮的 `off`、总抽相应 +N，本轮仍算**直出**；不要留给下一个 UP，否则下一位会被误判成「先歪」。它若在 UP 之前出，就是常规的先歪。抽数只算一次，用该频道官方 `gacha_count` 校验柱状总和（例：2372 = 官方值）。
- **指标**：
  - 每 UP 需 = 角色池总抽 / UP 数（含歪成本，例 2372/27 = 87.9）
  - 不歪率 = 50/50 胜场 / 总 UP 轮数。十连副金归到 UP 轮后，该副金仍是一次 50/50 失败，它换来的下一个 UP 属于「保底获得」，**不计胜场**（数据上用 `guar: true` + `guarFrom` 记录来源）；示例 13/27 = 48.1%。
  - 平均每金 = 总抽 / S 数；常驻每金、每 UP 音擎、每邦布同理按各自频道
- **欧判定**：`直出` 或 `total ≤ 每 UP 均值`（歪了但更省也算欧）。
- **极欧**：`total ≤ 40 抽`。

## 2. 图形与配色

| 含义 | 颜色 |
|---|---|
| 极欧 ≤ 40 抽（本发） | 蓝 `#3F7BFF` |
| 极欧周期的歪段 | 深蓝 `#1B3C78` |
| 欧 > 40 抽（本发） | 深绿 `#2E8F45` |
| 欧周期的歪段 | 深绿 `#1B5E2A` |
| 非酋本发 | 亮红 `#FF5F6D` |
| 非酋歪段 | 深红 `#A81E28` |

- **堆叠柱**：下段＝歪掉的抽数，上段＝UP 本身；红＝非酋，绿/蓝＝欧，柱体本身表达运气。
- 柱顶写本轮总成本；**柱内各段写各自抽数**（段 < 8 抽不写，避免挤成一团）。
- **头像**：UP 头像浮在柱顶上方；有歪时歪出头像再高一层，**先出的在上、后出的在下**。头像 96px 圆形。例外：十连副金在 UP 之后出时（南宫羽 + 猫又），UP 占上层、副金占下层，仍遵守先出后出。
- **十连多金**：同 `record_time` 且 `sort` 差 ≤ 9 的两金。用青色圆点 `#7BE0FF` 标在对应柱上方（与柱顶/头像错开）。
- **累计不歪率**：金色 `#F2E23C` 折线，右轴 0–60%。
- **版本分隔**：灰色虚线标在版本切换处，不带文字。
- 横坐标只写版本号（`1.0`、`2.7`，不带 `v`）。
- **图例单行**：红柱＝歪了（非酋），深色段＝歪掉的抽数 · 蓝＝极欧 ≤ 40 抽 · 深绿＝欧 > 40 抽（歪了但 ≤ 87.9 也算欧）· 柱顶＝总成本 · 柱内＝各段抽数 · 头像上先下后 · 黄线＝累计不歪率（右轴）· 青点＝十连多金 ×N · 官方接口 · N 条 S 记录。

## 3. tooltip（axis trigger，逐行）

```
猫又 → 南宫羽（粗体，歪出/副金在前，UP 在后；无歪出时只写 UP 名）
卡池 v2.7
直出 44抽                        ← 未歪
保底获得 52 抽（猫又换来的）      ← 保底获得（guar）：上一发 50/50 输掉换来的垫保底，替换「直出」行
保底 108 抽，37 抽歪「11号」      ← 歪了：total，off，角色
本发十连双金                     ← 仅该发是双金时
似非不非，白赚大保底              ← 十连双金且本轮直出（非 UP 金出现在 UP 之后，不占用下一个 UP 的保底）时追加
累计不歪率 50%                   ← 该柱的累计值，永远最后一行；< 40% 追加 ⚠️（< 30% 两个、< 20% 三个）；≥ 50% 追加 🍀（≥ 60% 两个、≥ 70% 三个）
```

- 歪出角色名多个用 `、` 连接；名字本身带「」时不要再套一层（`「「11号」」` 是错的）。
- 归属：同一发十连里后出的非 UP 金，算在**同池 UP 那一轮**（总抽 +该金到上一个金的差值），不要留给下一个 UP，否则下一位会被误判为「先歪」；全表总抽不变。
- 其他标签页/图例保持一行可读。

## 4. 称号与标签

基准：角色池每 UP 期望 = 62.5 抽/金 × 1.5（50/50）= **93.75 抽**。称号只看「角色池每 UP 均（含歪）」。

### 4.1 大标题（h1）

| 每 UP 均 | 称号 |
|---|---|
| ≤ 65 | 千里挑一尊贵欧皇 |
| ≤ 89 | 欧气满满大欧皇 |
| ≤ 100 | 再接再厉小欧皇 |
| ≤ 110 | 薛定谔的非欧 |
| ≤ 125 | 超级至尊非酋 |
| ≤ 150 | 千里挑一大非酋 |
| > 150 | 万劫不复大非酋 |

示例账号 87.9 → `欧气满满大欧皇`。称号按公式算出来再写进标题，不要写死；改数据后先核对落在哪一档。

### 4.2 定性标签（按事件，不与称号挂钩）

- `欧气附体`：十连双金 ≥ 1 次，或极欧（≤ 40 抽）柱 ≥ 2 根。
- `运势极佳`：最长连 UP ≥ 4。
- 非酋侧替换：最长连歪 ≥ 3 → 红色 `时运不济`；每 UP 均 > 110 → 红色 `非酋附体`。
- 条件不满足就不出现，不要为了好看硬凑；非酋账号自然只剩负向标签。

### 4.3 计数标签

- 连 UP：`代理人 K 连 UP ×N`，K＝最长连续直出；**同一长度出现多次才加 ×N**。
- 连歪：`代理人 K 连歪 ×N`，规则同上；更长的一档（如 4 连歪）另立一个标签，不合并。
- 十连多金：`十连双金 ×N`，**不写人名**。
- 似非不非：`似非不非 ×N`，条件＝该轮**先歪**（off > 0 且 direct = false）但总抽 < 87.9（看起来非、实际成本低于均值），蓝色标签；十连里白捡非 UP 金的直出轮不算。
- 配色：黄色＝正向，红色＝连歪，青色＝双金，蓝色＝似非不非。

### 4.4 悬浮详情

- 计数类标签 hover 显示具体轮次（版本 + 角色链）。用 `data-tip` + CSS 气泡（`::after` + `attr(data-tip)`），**不要用原生 `title`**（样式不可控、有延迟）。
- 换行在属性值里用 `&#10;`，气泡 `white-space: pre`；深色气泡 + 小三角，`z-index ≥ 30`。
- `cursor: pointer`，与图表 hover 行为一致。
- 联动高亮：标签用 `data-bars` 记录索引区间（如 `12-15;18-21`，分号分隔多段），`mouseenter` 时对每根柱 `dispatchAction({type:'highlight', seriesIndex:[0,1], dataIndex:i})`，并 `setOption` 一段临时 `markArea`（`rgba(240,240,241,0.07)`，整列高度）作灰色区间带；`mouseleave` 时 `downplay` + 清空 `markArea`。柱体 `emphasis` 用 1px 白色描边 + 淡黄色微光，保证高亮可见。

## 5. 头部

- 标题行：`昵称 | 大标题 | UID 胶囊 | 隐私开关`（同一行，不单独占行）。
- 次行：`总抽卡数 / 平均每金 / S 级总数 / 角色池`，行尾跟 `国服 prod_gf_cn · vX → vY · 采集 MM-DD HH:MM`（灰色等宽小字，斜杠分隔）。
- KPI 固定 5 格一行（窄屏也不折行），只保留最关键的 5 个。
- 隐私开关：UID 胶囊右侧一个眼睛按钮，**三态循环**（默认全显示）：① 全显示 → ② 仅打码 UID（`UID 116***92`）→ ③ 全打码（`天*` + `UID 116***92`）→ 回到 ①。打码规则：昵称只留首字、UID 只留前 3 后 2，其余打 `*`。
- 图标用内联 SVG 三态（睁眼 / 睁眼加斜线 / 闭眼），由按钮 `data-state="0|1|2"` 切显隐；`title` / `aria-label` 写下一步动作：`打码 UID` → `打码昵称` → `显示全部`。
- **对外截图（README、分享图）必须先点到「全打码」态（从默认点 2 下）**，再截图。

## 6. 实现约束

- 单文件 `report.html` + `assets/charts.js`，ECharts **SVG renderer**，`echarts.min.js` 与字体全部本地，禁止 CDN；图片用相对路径。
- 头像来源：`https://act-webstatic.mihoyo.com/game_record/zzzv2/role_square_avatar/role_square_avatar_<id>.png`，PIL 4× 超采样圆形遮罩缩到 96px。
- ECharts 技巧：
  - 头像：`scatter` + `symbol: 'image://…'`，x 用 **0 基索引** `[i, y]`，`symbolOffset` 做垂直错位（UP 一个高度、歪出再高一层）。
  - 柱内任意位置写字：`scatter` + `symbolSize: 1` + 透明 `itemStyle` + `label`。
  - 双 x 轴、`markLine` 百分比上限都已废弃，不要加回来。
- 单屏：`.wrap { height:100vh; display:flex; flex-direction:column }`，图表区 flex 撑满；1440×900 与 1280×800 必须无滚动、图例单行。
- 验证：headless Chrome `--window-size=1440,900|1280,800` + `--virtual-time-budget=2500` + `--hide-scrollbars` 截图核对；tooltip 用临时副本注入 `dispatchAction({type:'showTip'})` 截图，用完删除。
